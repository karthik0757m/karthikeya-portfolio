Data analysis / Music

Spotify Analysis

An exploration of emotional trends in music using Spotify audio features.

Explore source ↗

PROJECT CONTEXT
Personal project · Analysis in R

FOCUS
R
Data analysis
Visualization

The question

How do the emotional characteristics of music vary across time and genres? This analysis explores those patterns through Spotify audio-feature data.

The approach

The repository describes mood classification based on valence, energy, and danceability, along with yearly trend analysis and genre-based emotional mapping.

Tools and interpretation

The workflow is written in R, with packages including tidyverse, ggplot2, plotly, and leaflet. Audio-feature proxies can support exploration, but they do not capture every listener’s subjective experience. No unverified performance or impact metrics are claimed here.
