Disaster response / Web application

SafePathFinder

A disaster-routing project exploring how delay-tolerant networking can support navigation when internet connectivity is unavailable.

The problem

During a disaster, a route can become unsafe just as connectivity becomes unreliable. The project investigates how route guidance can account for these constraints.

The approach

The project concept uses delay-tolerant networking: messages can be stored, carried, and forwarded between available nodes instead of depending on a continuous internet connection. The browser demo, titled EvacGuard AI, begins with a profile flow covering age, mobility, health, and group information.

Implementation context

The repository identifies a React and TypeScript frontend built with Vite and Tailwind CSS. The diagram above explains the DTN concept; it is not a screenshot of a deployed mesh network.

Scope and limitations

This is an academic project, not a validated emergency-navigation service. The live web interface does not by itself establish offline device-to-device communication or real-world route safety. Open the repository to inspect the current implementation.
